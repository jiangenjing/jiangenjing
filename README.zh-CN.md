## 我的产品思维

**用户需求 → 工作流程 → 技术设计 → 可衡量的结果。**

- **客服场景：** 回答不仅要通顺，还要解决问题，或明确下一步由谁做什么。
- **充电场景：** 推荐兼顾用户时间与履约可靠性，增长方案同时考虑权益和交付成本。
- **供应链场景：** 不只看预测误差，还看预测如何影响库存、履约与经营决策。
